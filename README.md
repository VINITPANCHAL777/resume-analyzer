# Resume Analyzer

A web-based application for analyzing resumes against job descriptions and providing detailed scoring and feedback.

## Features

- Resume analysis against multiple job roles
- Skill matching and gap identification
- Experience relevance assessment
- ATS compatibility scoring
- Comprehensive analysis breakdown

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/resume-analyzer.git
   ```

2. Open `index.html` in your web browser or use a live server.

## Usage

1. Select a job role from the dropdown
2. Upload or paste your resume content
3. Click "Analyze Resume" to get detailed feedback

## Project Structure

- `index.html` - Main HTML file
- `style.css` - Styling
- `app.js` - Application logic and data
- `resume_analyzer_architecture.json` - Architecture details
- `sample_analysis.json` - Sample analysis data
